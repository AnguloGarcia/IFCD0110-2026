Ejemplos de input telefono y texto con pattern

Telefono movil espanol

Ejemplo valido: 612345678 pattern="[67][0-9]{8}"

Telefono fijo espanol

Ejemplo valido: 912345678 pattern="[89][0-9]{8}"

Telefono con prefijo internacional

Ejemplo valido: +34612345678 pattern="\+34[0-9]{9}"

Telefono separado con guiones

Ejemplo valido: 612-345-678 pattern="[0-9]{3}-[0-9]{3}-[0-9]{3}"

Telefono con espacios

Ejemplo valido: 612 345 678 pattern="[0-9]{3} [0-9]{3} [0-9]{3}"

Texto: nombre solo con letras

Ejemplo valido: Jose Luis pattern="[A-Za-z ]{3,}"

Texto: limitar letras

Ejemplo valido: Madrid pattern="[A-Za-z]{3,8}"

Texto: evitar simbolos

Ejemplo valido: Jose2026. No acepta @, -, _, ., ! ni espacios. pattern="[A-Za-z0-9]+"

Texto: codigo postal

Ejemplo valido: 08001 pattern="[0-9]{5}"

Texto: DNI

Ejemplo valido: 12345678A pattern="[0-9]{8}[A-Z]"

Texto: nombre de usuario

Ejemplo valido: jose_2026 pattern="[A-Za-z0-9_]{4,12}"

Guia rapida

Los patrones sirven para validar lo que escribe el usuario.

  • [0-9] acepta un numero.
  • [A-Z] acepta una letra mayuscula.
  • [A-Za-z0-9] evita simbolos.
  • {5} exige 5 caracteres.
  • {4,12} exige entre 4 y 12 caracteres.

El borde verde significa correcto y el rojo indica que falta ajustar el texto.

# Guía de inicio - IFCD0110

Bienvenido a tu repositorio de ejercicios del curso IFCD0110.

## ¿Qué contiene este proyecto?

Este repositorio guarda ejercicios de HTML, CSS y algunos ejemplos multimedia.

Estructura principal:

- Carpeta `html/`: todas las páginas de ejercicio en HTML.
- Carpeta `css/`: todos los estilos de los ejercicios.
- Carpeta `images/`: todas las imágenes usadas en los ejercicios.
- Carpeta `IMGS/`: conserva solo archivos comprimidos `.zip`/`.rar` y vídeos `mp4`.
- Archivos `.rar` y `.zip`: versiones comprimidas de ejercicios.

## Cómo empezar

1. Abre la carpeta `IFCD0110` en Visual Studio Code.
2. Abre cualquier archivo `*.html` en el editor.
3. Usa "Live Server" para ver la página en el navegador en tiempo real, o simplemente abre el archivo HTML directamente desde el explorador.

## Ejercicios recomendados para comenzar

- `selectorcss.html` / `selectorcss.css`: fundamentos de selectores CSS.
- `pseudoclases35.html` / `pseudoclases35.css`: pseudoclases y estados.
- `flex-direction.html`: diseño con Flexbox.
- `grid.html`: diseño con CSS Grid.
- `animaciones.html` / `animaciones.css`: animaciones básicas.
- `menus2.html` / `menus2.css`: menús y submenús.
- `translate.html` / `transicions.html`: transformaciones y transiciones.

## Cómo estudiar con este repositorio

- Lee el HTML y observa la estructura de etiquetas.
- Examina el CSS para entender cómo afectan los estilos a cada elemento.
- Modifica valores y recarga la página para ver el efecto.
- Copia ejercicios pequeños y prueba tus propias variantes.

## Extensiones de VS Code útiles

- Live Server
- Prettier - Code formatter
- HTML CSS Support
- IntelliSense for CSS class names in HTML
- Auto Rename Tag

## Buenas prácticas

- Guarda cada ejercicio con un nombre claro.
- Mantén separados HTML y CSS.
- Usa comentarios cuando necesites recordar qué hace cada sección.
- Prueba cambios pequeños uno a uno.
